# CoinDom — Cryptocurrency Information Platform

A React.js web application that displays live cryptocurrency market data — prices, trends, and historical information — using third-party crypto APIs.

🌐 **Live:** [coindom.surge.sh](https://coindom.surge.sh)

## Screenshot

![CoinDom Dashboard](screenshots/coindom.png)

## Features

- Live cryptocurrency prices from third-party APIs
- 24h market change tracking
- Market cap rankings
- Responsive UI built with React and Tailwind CSS
- Mobile navigation menu

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React.js, HTML5, CSS3 |
| Styling | Tailwind CSS |
| HTTP Client | Axios |
| Data Source | Cryptocurrency market APIs |

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Run Locally

```bash
git clone https://github.com/m-ahmadjaved/CoinDom.git
cd CoinDom
npm install
npm start
```

The app opens at `http://localhost:3000`.

### Build for Production

```bash
npm run build
```
